# RGMS (Ranking of Global Music School)

This is a premium, static website that ranks global music conservatories, inspired by top university ranking platforms.

## Project Structure

- `index.html`: Main website entry point.
- `css/style.css`: Custom premium styling.
- `js/data.js`: Mock data containing school rankings.
- `js/app.js`: Logic for rendering, searching, and sorting.

## How to Run Locally

Since this project uses Vanilla HTML/CSS/JS with no build system, running it is extremely simple:

1. Navigate to the project folder: `./RGMS`
2. Double-click `index.html` to open it in your default web browser.

## Features

- **Premium Aesthetics**: Dark mode, gold accents, and lush gradients.
- **Dynamic Sorting**: Sort by score (High/Low).
- **Live Search**: Filter by institution name or location.
- **Region Filtering**: Filter by continent (Europe, Asia, North America).
- **Responsive Design**: Works on mobile and desktop.
